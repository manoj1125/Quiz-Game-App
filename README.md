## ✨ Features

* **Interactive Gameplay:** Select answers and get immediate visual feedback on correct and incorrect responses.
* **Dynamic Score Calculation:** Tracks and calculates your final score in real-time.
* **Countdown Timer:** *(Optional: Include if your app has a timer feature)* Timer adds an extra layer of challenge.
* **Fully Responsive Design:** Optimized for seamless play across desktop, tablet, and mobile screens.
* **Replay / Restart Option:** Retake the quiz anytime without refreshing the browser.
